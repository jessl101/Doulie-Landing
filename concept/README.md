# Landing page concept: The Long Night

Exploration for a cinematic redesign of the marketing page. Nothing here is
wired into the live site; `index.html` at the repo root is untouched.

- `index.html`     Working prototype: 3D star field (Canvas), scroll-driven
                   sky, one night told in hours. No dependencies. Forms do
                   not submit.
- `direction.html` The creative direction: concept, storyboard, palette
                   roles, type scale, materials, camera language, motion,
                   emotional beats, and a two-phase build plan.

Serve the repo root (`python3 -m http.server 8000`) and open `/concept/`.
The prototype loads Instrument Serif and Instrument Sans from Google Fonts;
production would keep Satoshi from Fontshare.
